## Twinrova Shield Effects
Setting up effects for the Mirror Shield absorbing fire and ice during the Twinrova boss fight.

There are four DLs for the Twinrova shield effects, all of which can be found in `object_tw`:  
`gTwinrovaMirrorShieldFireChargeCenterDL`  
`gTwinrovaMirrorShieldFireChargeSidesDL`  
`gTwinrovaMirrorShieldIceChargeCenterDL`  
`gTwinrovaMirrorShieldIceChargeSidesDL`  

Import each of these into blender using the DL importer
